# Arch BTW

I’ve been daily driving Arch Linux for the last couple of years, and at this point I genuinely can’t go back.

Everything is built and configured from scratch — no unnecessary bloat, no hidden abstractions, just a system tuned exactly the way I want it. That level of control over performance, workflow, security, and resource usage is what makes Arch unbeatable for me.

## Setup Highlights

* Minimal and fully customized Arch installation
* Lightweight and fast workflow powered by Hyprland
* Highly optimized terminal-centric environment
* System-wide Vim motions and keybindings
* Custom-configured Neovim setup capable of replacing most traditional IDEs
* Keyboard-driven browsing with qutebrowser
* Carefully refined through countless hours of tweaking and experimentation

## Workflow Philosophy

The biggest productivity boost comes from consistency.

Using Vim bindings everywhere — terminal, browser, file manager, editor, launchers — creates a seamless workflow where navigation becomes muscle memory.

The result is a setup that feels:

* Faster
* Cleaner
* More focused
* Extremely efficient on resources

This environment has been refined over many sleepless nights of trial, error, optimization, and customization.
